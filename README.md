# Huck's Good Life Website

Static landing page mockup for Huck's Good Life.

## How to use

1. Upload these files to your GitHub repository.
2. Go to Settings > Pages.
3. Choose "Deploy from a branch".
4. Select `main` and `/ (root)`.
5. Visit the GitHub Pages URL after it publishes.

Main files:
- `index.html`
- `styles.css`
- `assets/`
